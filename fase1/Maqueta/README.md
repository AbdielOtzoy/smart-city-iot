# Participación en la Maqueta

## Descripción General
Este documento describe la participación en la construcción de la maqueta del proyecto.

## Aportaciones Christian Chinchilla

1. **Construcción de la base de la maqueta**
   - Realicé la estructura base que sirve como soporte principal de toda la maqueta.

2. **Encapsulamiento**
   - Diseñé y elaboré el encapsulamiento para proteger y mantener estables los componentes.

3. **Pintura**
   - Pinté tanto la base como el encapsulamiento para mejorar la estética y proteger los materiales.

4. **Refuerzo estructural**
   - Utilicé duropor para reforzar la maqueta y garantizar su durabilidad.

5. **Preparación para el cableado**
   - Realicé los agujeros en la base para permitir el paso del cableado de manera ordenada.

6. **Colaboración en el diseño**
   - Apoyé en el boceto inicial de la maqueta, aportando ideas y sugerencias.

7. **Toma de medidas**
   - Realicé las mediciones necesarias para asegurar la precisión y proporción de la maqueta.
