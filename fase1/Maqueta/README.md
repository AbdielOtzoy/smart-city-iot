# Participación en la Maqueta

## Descripción General
Este documento detalla la participación de los integrantes en la construcción de la maqueta del proyecto, describiendo las tareas realizadas por cada uno para su desarrollo y finalización.

## Aportaciones de Christian Chinchilla

1. **Construcción de la base de la maqueta**  
   Elaboró la estructura base que funciona como soporte principal de toda la maqueta.

2. **Encapsulamiento**  
   Diseñó y fabricó el encapsulamiento para proteger y mantener estables los componentes.

3. **Pintura**  
   Pintó tanto la base como el encapsulamiento, mejorando la estética y protegiendo los materiales.

4. **Refuerzo estructural**  
   Implementó refuerzos con duropor para aumentar la resistencia y durabilidad de la maqueta.

5. **Preparación para el cableado**  
   Perforó la base para permitir el paso ordenado del cableado.

6. **Colaboración en el diseño**  
   Participó en la elaboración del boceto inicial, aportando ideas y sugerencias.

7. **Toma de medidas**  
   Realizó las mediciones necesarias para asegurar la precisión y proporción de la maqueta.

## Aportaciones de Daniel Ortiz

1. **Semáforos**  
   Construyó la estructura de los semáforos incluidos en la maqueta.

2. **Cableado**  
   Efectuó las mediciones del cableado para optimizar la conexión de todos los elementos.

3. **Colaboración en el diseño**  
   Adquirió plantas artificiales para mejorar la estética de la maqueta.

4. **Botones de pánico**  
   Elaboró la base para la instalación de los botones de pánico.
