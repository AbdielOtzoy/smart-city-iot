# 🌍 Proyecto de Gestión Inteligente de Tráfico y Seguridad Ciudadana  

Este proyecto busca aportar soluciones innovadoras a los desafíos de **movilidad** y **seguridad ciudadana** en zonas históricas de alta densidad, tomando como referencia el **Centro Histórico de la Zona 1 de Guatemala**.  

La propuesta combina **Internet de las Cosas (IoT)**  para crear un sistema integral que permite:  
- Monitorear en tiempo real el flujo vehicular.  
- Detectar incendios y sismos simulados.  
- Activar alertas de emergencia mediante botones de pánico.  
- Reconocer comportamientos de riesgo como cruces en rojo.
- Mejorar la movilidad urbana y la seguridad ciudadana de forma proactiva.  

## 🚀 Tecnologías utilizadas  

- **Hardware:**  
  - Arduino (arquitectura de un solo microcontrolador)  
  - Sensor ultrasónico HC-SR04  
  - Sensor MQ-135 (detección de gases)  
  - Push buttons (botones de pánico)  
  - Piezos (simulación de sismos)  
  - LEDs (semáforos)  
  - Buzzers (alarmas sonoras)  

- **Software & Comunicación:**  
  - Processing (dashboard de visualización en tiempo real)  
  - Arduino IDE (programación de microcontroladores)

## 🎯 Objetivo  

Desarrollar un sistema inteligente, escalable y accesible que **optimice la movilidad urbana, refuerce la seguridad ciudadana y fomente el turismo**, aplicando tecnologías modernas de IoT y computación distribuida.
